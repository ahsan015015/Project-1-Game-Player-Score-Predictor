# 🎮 Game Player Score Predictor

A beginner-friendly Machine Learning project that predicts a player's **game score** based on their gameplay statistics — such as play time, enemies killed, damage taken, and balls collected.

This project is built as a **first ML project** for developers who already know basic programming and want to learn the complete Machine Learning workflow end to end.

---

## ✨ What It Does

You give the model some gameplay stats:

| Input | Example Value |
|-------|---------------|
| Play Time (seconds) | 60 |
| Enemies Killed | 12 |
| Damage Taken | 25 |
| Balls Collected | 8 |

...and it predicts:

```text
Predicted Score: 755.4
```

The model is a **Linear Regression** model trained on a sample gameplay dataset.

---

## 🧠 Machine Learning Workflow

```text
Collect Data
    ↓
Prepare Dataset (CSV)
    ↓
Split into Train / Test
    ↓
Train Linear Regression Model
    ↓
Evaluate (MAE, MSE, R²)
    ↓
Make Predictions
    ↓
Deploy as a Web App (Streamlit)
```

## 🚀 Getting Started (From Scratch)

Follow these steps **in order**. They assume you are on Windows using PowerShell, but notes for macOS/Linux are included.

### Step 1 — Open the project folder in a terminal

```powershell
cd "C:\path\to\Project-1-Game-Player-Score-Predictor"
```

### Step 2 — Create a virtual environment

A virtual environment keeps this project's libraries separate from other projects.

```powershell
python -m venv venv
```

This creates a `venv/` folder. You only need to do this **once**.

### Step 3 — Activate the virtual environment

**Windows (PowerShell):**

```powershell
venv\Scripts\Activate.ps1
```

If you get a *"running scripts is disabled on this system"* error, run this once, then try activating again:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

**Windows (Command Prompt / CMD):**

```cmd
venv\Scripts\activate
```

**macOS / Linux:**

```bash
source venv/bin/activate
```

When it works, you'll see `(venv)` at the start of the terminal line:

```text
(venv) PS C:\...\Project-1-Game-Player-Score-Predictor>
```

> ⚠️ **Always activate the venv before running any `python` or `pip` command.** Every time you open a new terminal, re-run the activate command.

### Step 4 — Install the required libraries

```powershell
pip install -r requirements.txt
```

Or install them manually:

```powershell
pip install pandas scikit-learn matplotlib joblib streamlit
```

Verify the install with:

```powershell
pip list
```

You should see `pandas`, `scikit-learn`, `matplotlib`, `joblib`, and `streamlit`.

## 🧪 How to Use — Running the Project

Make sure `(venv)` is active and you are in the project's root folder. Run these in order.

### 1️⃣ Train the model

```powershell
python src/train.py
```

What it does:
1. Loads `data/game_data.csv`
2. Splits the data into training (80%) and testing (20%) sets
3. Trains a `LinearRegression` model
4. Prints the learned coefficients and the **R² score**
5. Saves the trained model to `models/score_model.pkl`

Expected output (your numbers may differ slightly):

```text
Total data: 50 | Training: 40 | Testing: 10
R² Score: 0.9966
Model saved: models/score_model.pkl
```

### 2️⃣ Predict a score for a new player

```powershell
python src/predict.py
```

It loads `models/score_model.pkl`, feeds it a sample player's stats, and prints:

```text
Player Info:
   Play Time       : 60
   Enemies Killed  : 12
   Damage Taken    : 25
   Balls Collected : 8

=> Predicted Score : 755.4
```

You can edit the numbers inside `src/predict.py` to predict for other players.

### 3️⃣ Evaluate the model

```powershell
python src/evaluate.py
```

It prints three accuracy metrics and saves a graph:

```text
MAE  : 7.00
MSE  : 81.20
R²   : 0.9966
Graph saved: models/evaluation_plot.png
```

Open `models/evaluation_plot.png` — the closer the dots are to the red dashed line, the more accurate the model.

## 📊 Understanding the Metrics

| Metric | Full Name | Meaning | Good Value |
|--------|-----------|---------|------------|
| **MAE** | Mean Absolute Error | Average points the prediction is off by | Lower is better |
| **MSE** | Mean Squared Error | Squared average error (penalizes big mistakes) | Lower is better |
| **R²** | R-squared Score | How much variance the model explains (0 to 1) | Close to 1.0 |

Our current model scores **R² ≈ 0.997**, meaning it explains about 99.7% of the score pattern — excellent for a learning dataset.

## 🔧 Troubleshooting

**`ModuleNotFoundError: No module named 'pandas'`**
→ The virtual environment is not activated. Run `venv\Scripts\Activate.ps1` (PowerShell) or `venv\Scripts\activate` (CMD), then try again.

**`FileNotFoundError: ... score_model.pkl`**
→ You ran `predict.py` or `evaluate.py` before training. Run `python src/train.py` first.

**`FileNotFoundError: ... game_data.csv`**
→ You're running the command from the wrong folder. `cd` into the project root (the folder that contains `data/`, `src/`, and `app.py`).

**`streamlit : command not found`**
→ Streamlit isn't installed. With `(venv)` active, run `pip install streamlit`.

**PowerShell: "running scripts is disabled"**
→ Run:
```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

**GitHub push rejected**
→ Make sure you ran `git remote add origin <your-repo-url>` and that you're pushing to the correct branch (`main`).
